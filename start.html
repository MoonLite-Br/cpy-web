Getting Started

Install Cpy and execute your first scripts on Linux, Termux, and Debian systems.

Installation CLI Options

Installation

Linux (Build from Source)

Clone the repository and execute the automated installation script:

git clone https://github.com/MoonLite-Br/Cpy.git
cd Cpy
./install.sh

Termux (Android)

Install required build tools and dependencies before running the installer:

pkg install clang make openssl
git clone https://github.com/MoonLite-Br/Cpy.git
cd Cpy
./install.sh

Prebuilt Debian Package (.deb)

Download the official .deb package or prebuilt binary directly from the releases page and install via package manager:

sudo dpkg -i cpy_1.11.0_amd64.deb

Note: Standalone binaries and Debian release packages for v1.11.0 are hostable and downloadable directly from GitHub Releases.

First Commands

Write your first Cpy script and execute it using the CLI interpreter.

Creating a Script

Save the following content as hello.cpy:

def main():
    print("Hello, Cpy!")

main()

Run the script directly from your terminal:

cpy hello.cpy

CLI Reference Table

Command Description
cpy <script.cpy> Executes a source file.
cpy Starts the interactive REPL shell.
cpy -c "<code>" Executes inline string code directly.
cpy -v, cpy --version Displays version information (1.11.0).
cpy -h, cpy --help Prints command line help and arguments list.

Notice: Ensure OpenSSL development libraries are available if standard networking modules are built from source.
