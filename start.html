Start

Install and run your first script.

Requirements

  • C compiler (clang or gcc) and make
  • Optional: OpenSSL for https://

Linux

sudo apt install build-essential libssl-dev
git clone https://github.com/MoonLite-Br/Cpy.git
cd Cpy
./install.sh

Termux

pkg install clang make openssl
git clone https://github.com/MoonLite-Br/Cpy.git
cd Cpy
./install.sh

Debian package

sudo dpkg -i cpy_1.11.0-1_amd64.deb

First commands

cpy
cpy script.cpy
cpy -c 'print(1 + 2)'
cpy --version
