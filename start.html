Start

Install cpy and run your first script.

Requirements

  • A C compiler (clang or gcc) and make
  • Optional: OpenSSL headers for https:// in urllib

Linux / macOS

# Debian/Ubuntu
sudo apt install build-essential libssl-dev

git clone https://github.com/MoonLite-Br/Cpy.git
cd Cpy
./install.sh          # builds and puts cpy on PATH
# or: make && ./bin/cpy

Termux (Android)

pkg install clang make openssl
git clone https://github.com/MoonLite-Br/Cpy.git
cd Cpy
./install.sh

Debian package

# from GitHub Releases (amd64)
sudo dpkg -i cpy_1.11.0-1_amd64.deb

# or build locally
./scripts/build-deb.sh 1.11.0
sudo dpkg -i build/cpy_*.deb

First commands

cpy                     # REPL
cpy script.cpy          # run a file (.cpy or .py)
cpy -c 'print(1 + 2)'
cpy --version
Module search path: set CPY_PATH=dir1:dir2. Force tree-walker only with --no-vm or CPY_NOVM=1.
