How cpy Works Under the Hood

Combining clean Python syntax with raw C speed. Discover the pipeline, execution engines, and low-level architectural optimizations powering cpy.

Execution Pipeline Overview

cpy translates high-level Python syntax directly into lean runtime execution through a multi-stage pipeline designed for minimum allocation and maximum speed.

1. Parsing

The lexer and parser process code source into a light Abstract Syntax Tree (AST), stripping overhead while maintaining source locations for precise errors.

2. Scope & Symbol Resolution

Variables and scopes are resolved ahead of time. Identifiers are mapped to static indices, turning costly runtime hash lookups into instant direct access.

3. Runtime Dual Engine

Executes via a fast tree-walk interpreter by default, or delegates to an optional bytecode VM runtime for high-throughput loops and compute-heavy paths.

Core Architectural Features

Locals as Fixed Slots

Instead of dynamic dictionary lookups for local variables, cpy allocates local scopes as contiguous stack slots. Accessing a local is simply a direct offset read.

Generators via ucontext

Generators and yield operations rely on C system-level context switching using standard ucontext primitives, keeping generator frame suspension lightweight and native.

Inline Method Cache

Method dispatch employs a global inline cache. Repeated calls to the same method target bypass dynamic class lookup, matching native struct call performance.

64-bit Native Integer Engine

Numeric evaluations use direct native 64-bit signed integers throughout the system, ensuring zero allocation overhead during arithmetic operations.

Engine Design Principles

Lightweight Footprint: To maintain standard C compilation speeds and low binary size, cpy explicitly excludes heavy abstractions like native bytes mutability structures or complex match pattern-matching trees.

Optional Bytecode VM: The optional VM runtime can be toggled at build time. When disabled, cpy falls back entirely to the optimized tree-walk AST runtime.

Portability & Toolchain Requirements

cpy v1.11.0 compiles anywhere a modern C compiler is present. It runs seamlessly on standard Linux, macOS, and mobile environments like Termux using basic development tools: clang / gcc, make, and openssl for cryptographic primitives.
