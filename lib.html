Built-in Functions & Types

cpy provides a fast, lightweight set of built-in functions optimized for the 64-bit virtual machine architecture.

Name Type / Signature Description Notes
int int(x=0) Converts a number or string to a native 64-bit signed integer. Full 64-bit int precision
float float(x=0.0) Converts a number or string to a 64-bit double-precision float. IEEE 754 standard
str str(object='') Returns a string representation of an object. UTF-8 encoded
bool bool(x=False) Converts a value to a Boolean (True or False). Truthy / Falsy semantics
list list([iterable]) Mutable sequence object for dynamic arrays. Dynamic resize support
dict dict(**kwargs) Hash table mapping key-value pairs. Fast insertion & lookup
tuple tuple([iterable]) Immutable sequence object. Low-memory overhead
print print(*args, sep=' ', end='\n') Prints object values to standard output. Buffered stdout
len len(s) Returns the number of items in a container. O(1) complexity
range range(start, stop[, step]) Generates an immutable sequence of integers. Memory efficient iterator
type type(object) Returns the internal type of the object. Fast type checking
open open(file, mode='r') Opens a file and returns a corresponding file stream object. POSIX wrapper
input input([prompt]) Reads a line from standard input stream. Returns string
Integer Performance Note: All integer operations in cpy v1.11.0 run on native 64-bit registers, ensuring fast execution across Linux systems and mobile Termux environments without big-integer allocation overhead.

Standard Library Modules

The standard modules built into cpy offer essential system, math, and networking capabilities.

Module Category Key Capabilities Backend Requirements
sys System Command-line arguments (sys.argv), exit calls (sys.exit), version string. Core VM
os OS Interface File path operations, environment variables, directory listing, process management. POSIX / Termux API
math Mathematics Trigonometric functions, logarithms, square root, mathematical constants (pi, e). C math library (libm)
time System Time Monotonic clock access, execution pause via sleep(), timestamp generation. System clock
ssl Security TLS/SSL sockets, secure hashing primitives, cryptographic operations. OpenSSL dependency
json Data Format JSON parsing (loads) and serialization (dumps). Core VM
OpenSSL Dependency: The ssl module relies on system OpenSSL libraries. When building via install.sh on Termux or bare-metal Linux, ensure `openssl-dev` or `libssl-dev` packages are installed.

Module Overview

Core Builtins

Designed for fast execution with zero external runtime dependencies. Integrated directly into the cpy VM bytecode executor.

System & POSIX

Modules like sys and os map directly to native C system calls for maximum execution speed on Termux and Linux.

Crypto & Security

Full support for OpenSSL bindings allows secure HTTPS requests and cryptographic hashing inside cpy scripts.
