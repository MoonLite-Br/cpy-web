Lib

Built-ins and standard modules shipped inside the binary.

Always available

These names exist without an import (same idea as CPython builtins):

print len range type isinstance issubclass iter next list dict set tuple str int float bool abs min max sum sorted reversed enumerate zip map filter open input repr hash id callable hasattr getattr setattr delattr any all round divmod pow chr ord hex bin oct Exception and the usual exception hierarchy…

Also: read("file") / write("file", text) conveniences.
