cpy Virtual Machine & Evaluation

Combine Python syntax with high C speed. Choose between light startup and compiled bytecode execution.

Install v1.11.0 Try Examples
Default

Tree-Walker Interpreter

By default, cpy uses a fast AST tree-walker execution model. It offers immediate startup, zero byte-compilation overhead, and seamless integration with native C data structures.

Optional

Bytecode VM Engine

For compute-heavy tasks, an optional bytecode VM engine is available. It converts expressions into optimized instructions to leverage 64-bit int performance and raw speed.

Verification

Dual-Engine Tests

Correctness is prioritized. Test suites automatically run against both engines, comparing execution results between the tree-walker and the VM to ensure identical behavior.

Disabling the VM Architecture

If you want a minimal footprint, you can completely strip the bytecode VM during build time. Run install.sh --no-vm or define CPY_NOVM during C compilation.

Language Engine Scope

Regardless of the active engine (tree-walker or bytecode VM), cpy sticks strictly to lightweight primitives with 64-bit int precision. Features like bytes and match statements are deliberately omitted.

Building on Minimal Systems

cpy v1.11.0 compiles anywhere with standard C tooling, including Termux using clang, make, and openssl support.
