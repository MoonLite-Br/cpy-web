VM

Optional bytecode tier next to the tree-walker.

Two execution engines

cpy always has a tree-walker. A register-style bytecode VM can take over for eligible functions. Results must match: the test suite compares tree-walk vs VM on every fixture.

cpy script.cpy          # VM allowed
cpy --no-vm script.cpy  # tree-walker only
CPY_NOVM=1 cpy script.cpy

What the VM is for

  • Dense arithmetic and tight loops without walking AST nodes every step
  • Still the same runtime values, exceptions, and tracebacks

Safety

tests/vm_fuzz.py and related harnesses randomly exercise agreement between engines. Prefer filing a bug if you ever see divergence.

Full opcode-level notes live in the upstream docs/vm.md in the GitHub repo; this page is the short tour.
