VM

Optional bytecode tier next to the tree-walker.

Two engines

cpy always has a tree-walker. A register-style bytecode VM can run eligible functions. The test suite checks that both agree.

cpy script.cpy           # VM allowed
cpy --no-vm script.cpy   # tree-walker only
CPY_NOVM=1 cpy script.cpy

Why

Dense arithmetic and tight loops avoid walking AST nodes every step, while sharing the same values, exceptions, and tracebacks.

If tree-walk and VM ever disagree on a program, that is a bug — please report it.
