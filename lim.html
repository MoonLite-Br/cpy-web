Limits

Honest differences from CPython.

Not the same as CPython

Areacpy behavior
int64-bit only; overflow raises (no bigint)
BytesNo bytes / bytearray
NumbersNo complex
SyntaxNo match / case
ObjectsNo __slots__; metaclasses limited
ConcurrencyCooperative async only (no user OS threads)
Everyday scripts that stick to the supported subset often run unmodified. Large CPython-only ecosystems (native extensions, full stdlib, packaging tools) are out of scope.

When to use cpy

  • Small tools and scripts you want as one binary
  • Termux / limited environments
  • Learning interpreters by reading ~10k lines of C
