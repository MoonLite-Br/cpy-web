cpy Known Limits

Python syntax with C speed. cpy achieves native performance by removing dynamic overhead and focusing on lightweight, statically determinable language features.

Get cpy v1.11.0 Quickstart Guide
Environment Requirements: Building cpy code requires clang, make, and openssl (works out of the box on desktop Linux/macOS and Android Termux via install.sh).

Language Scope & Technical Limits

To deliver raw execution speeds without runtime bloat, cpy deliberately omits certain features present in CPython. Execution can target native machine code or run through an optional VM interpreter.

Feature Area cpy Limit Description & Context
Integers 64-bit int Primitive int64 representation for zero-overhead arithmetic instead of arbitrary-precision big integers.
Bytes Type No bytes Raw byte handling relies on standard string/array primitives.
Complex Numbers No complex Built-in complex number mathematical operations are omitted.
Pattern Matching No match Structural pattern matching is not supported; standard conditional branching is used instead.
Class Attributes No __slots__ Classes are natively structured without explicit dynamic slot definitions.
Concurrency Cooperative async only Single-threaded, event-driven cooperative async without OS-level thread preemption.
Note on Execution: You can run scripts instantly using the optional VM or compile directly down to C binaries for max performance.

When to Use cpy

When to Use cpy

  • High-performance utilities where Python syntax and C speed are required.
  • Embedded devices or Android Termux environments needing small binaries with clang and openssl.
  • Event-driven, cooperative async network services and microservices.
  • Standalone tools deployed via a simple shell installation script (install.sh).

When NOT to Use cpy

  • Scientific computing requiring complex numbers or arbitrary-precision integers beyond 64-bit.
  • Heavy reliance on CPython third-party modules that require full byte-buffer manipulations or match syntax.
  • Applications dependent on pre-emptive multithreading instead of cooperative async loops.
