Lang

Language surface — a practical Python subset.

Lexical structure

  • Indentation defines blocks (tab = 4 columns). Lines inside ()[]{} continue; trailing \ continues a line.
  • Comments start with #.
  • Numbers: 42, 1_000, 0x1F, 0b101, 0o17, 3.14, 1e-3.
  • Strings: quotes, triple quotes, r/f prefixes; escapes \n \t \xHH \uXXXX…
  • Source encoding: UTF-8. Extensions: .cpy or .py.

Types

TypeNotes

floatIEEE double
boolTrue/False as 0/1

Control flow & functions

  • if / elif / else, while, for … in, break, continue
  • def with *args, **kwargs, keyword-only params, defaults
  • lambda, closures, global / nonlocal
  • try / except / else / finally, raise, assert
  • with (multiple managers)
  • Comprehensions: list, set, dict, generator
  • Walrus :=, f-strings including f"{x=}"

Classes

  • Multiple inheritance, C3 MRO
  • @decorator, @property, @staticmethod, @classmethod
  • Instance and class attributes; methods bind as usual

Generators & async

  • yield, yield from, .send / .throw / .close
  • Generators use a userspace stack switch (ucontext or sigaltstack) when available
  • async def / await with a cooperative event loop (asyncio-style)

Imports

import math
from collections import Counter
from . import sibling      # relative inside packages

Built-in modules are embedded in the binary; extra paths via CPY_PATH.
