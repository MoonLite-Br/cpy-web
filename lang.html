Language Specification

cpy Language Reference

Python syntax with C speed. Fast execution backed by tree-walk parsing and bytecode VM execution.

Data Types Overview

cpy implements a streamlined core set of built-in Python data types optimized for high performance.

Type Description Example
int 64-bit signed integer 42, -100
float 64-bit double precision float 3.14159
bool Boolean logical values True, False
str UTF-8 encoded string "hello"
list Dynamic mutable sequence [1, 2, 3]

NoneType Absence of value None

Language Syntax & Constructs

cpy retains clean, clean-bracket, Python-compliant syntax for ease of adoption and maximum readability.

  • Control Flow: Standard if, elif, else, while, and for loops over iterables.
  • Functions: Standard def function definitions with positional and keyword argument support.
  • Error Handling: Structured try, except, and finally blocks for exception safety.
  • Modules & Scope: Lexical scoping with global and nonlocal keyword support.

Unsupported Syntax & Types

To preserve lightweight execution and high execution speed, cpy does not include support for bytes, complex numbers, or structural pattern matching (match/case).

Classes & Object Model

Object-oriented programming in cpy supports dynamic class instantiation and inheritance.

  • C3 MRO: Method resolution order uses standard C3 Linearization to guarantee consistent multiple inheritance lookups.
  • Method Cache: Internal C-level method caching minimizes runtime lookup overhead for object method calls.
  • Dunder Methods: Standard __init__, __str__, __repr__, and arithmetic operator overrides.

Generators & Async Execution

cpy features built-in generator functions and non-blocking asynchronous primitives.

  • Generators: Dynamic stateful iteration via yield statements.
  • Cooperative Async: Lightweight asynchronous tasks utilizing async def syntax and standard await expressions.
  • Single-Threaded Event Loop: Efficient cooperative multitasking built into the execution engine.

Module & Import System

cpy uses a standard file-based module system to organize libraries and applications into reusable units.

Imports are resolved relative to the entry point file and standard library path:

import math
from os import path
import custom_module as mod

Execution Pipeline

Code evaluation combines standard tree-walk parsing for AST construction and an internal register-based virtual machine for fast execution.
