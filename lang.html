Lang

Practical Python subset that cpy runs.

Basics

  • Indentation defines blocks. Comments start with #.
  • Files: .cpy or .py, UTF-8.
  • Numbers: 42, 0x1F, 3.14, 1e-3.
  • Strings: quotes, f-strings, raw strings.

Types

TypeNotes
intSigned 64-bit; overflow raises
floatIEEE double
boolTrue / False
strImmutable UTF-8
list / tupleOrdered sequences
dictInsertion-ordered
set / frozensetHash sets
rangeLazy sequence

Language features

  • if / while / for, try / except / finally, with
  • def, lambda, *args, **kwargs
  • Classes, multiple inheritance, C3 MRO
  • @decorator, @property, static / class methods
  • Generators: yield, yield from
  • Comprehensions, walrus :=
  • async / await (cooperative)
  • import / from (relative imports too)
